# Quick Plan: Reasoning types per model (compatible only)

## Goal

Expose each model's supported **pensamento** (`reasoning_effort`) in the demo picker; show levels that exist; **drop** GPT-6-only levels (`xhigh`, `max`) that are not compatible with the shared surface used by other models (Gemini/Grok/gpt-4o family).

## Tasks

### Task 1: `reasoning.py` — per-model levels + validation
- `supported_reasoning_levels(api_tag, model) -> tuple`
  - OpenAI reasoning models (`gpt-5*`, `gpt-6*`, `o*`): `REASONING_LEVELS` only (no xhigh/max)
  - OpenAI non-reasoning: empty
  - Gemini / Grok: `REASONING_LEVELS`
- `assert_reasoning_compatible(...)` → ConfigError when level not allowed for that model
- Unit tests for gpt-6-luna/sol, gpt-4o-mini, intersection rule

### Task 2: Demo `/models` + UI filter
- `/models` entries: `{id, reasoning: [...]}` + top-level `reasoning_levels`
- `app.js`: label models that have thinking; rebuild reasoning `<select>` from selected model
- `serve.py`: reject POST when reasoning ∉ model.supported (400)
- Update demo tests

## Done when
- GPT-6 Sol/Luna show none|low|medium|high in UI; no xhigh/max
- gpt-4o-mini shows no reasoning options (or N/A)
- Offline tests green
