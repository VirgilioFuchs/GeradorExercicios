# Quick Plan: xhigh/max per model visibility

## Goal

GPT-6 / OpenAI reasoning models keep **`xhigh`** and **`max`** in their pensamento list. Switching to Gemini, Grok, or an OpenAI model without reasoning **hides** those options.

## Tasks

1. `reasoning.py` — `OPENAI_REASONING_LEVELS` includes xhigh/max; gemini/grok stay on base four; validate per model
2. Demo `/models` + `_VALID_REASONING` + CLI choices accept xhigh/max
3. Tests: gpt-6 shows xhigh/max; gemini/gpt-4o-mini do not; POST ok for gpt-6+xhigh, 400 for gemini+xhigh

## Done when
- Demo filters correctly on provider/model change
- Offline tests green
