- Package `__init__.py` re-exports public API via `__all__`
- Absolute imports rooted at `exercise-ai/` on `sys.path` (`from token_usage.X` → `from skills.generation.X`)

**Source:** `exercise-ai/token_usage/rates.py`, `exercise-ai/plan_ux.py`, `exercise-ai/reasoning.py`

**Source:** `exercise-ai/token_usage/collector.py` (`get_collector`)
**Apply to:** `persona.get_persona_system`
- Thin function, typed return, no side effects in Phase 16

**Apply to:** persona stub text + docstrings/TODO in `rules.py`

**Source:** `conftest.py` path insert + lightweight module tests (`test_model_catalog.py`, `test_plan_ux.py`)
**Apply to:** optional smoke test only
- No live LLM, no network, no `.env` secrets
