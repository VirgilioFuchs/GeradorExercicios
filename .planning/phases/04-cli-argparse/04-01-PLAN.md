## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| argv → argparse | Untrusted CLI strings cross into GenerationRequest / file path |
| process → --out filesystem | Write path chosen by user; must write only intended ExerciseBatch JSON |
| env → process | Existing dotenv API keys; CLI must not print them |
| stderr → developer | Stage labels + LOG-01 must stay free of key values |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Information Disclosure | argparse / LOG-01 / help text | high | mitigate | Never log or print `LLM_API_KEY` / `GEMINI_API_KEY` values; log request fields only; pytest asserts key absence (D-11 messages name env var names, not values) |
| T-04-02 | Tampering | `--out` file write | high | mitigate | Write only `validated_batch.model_dump()` JSON to the user-supplied path; do not echo secrets into the file; no extra sidecar dumps |
| T-04-03 | Information Disclosure | stderr user errors | medium | mitigate | Keep plain PT errors; reuse existing LOG-02 redaction; no new secret handling beyond dotenv |
| T-04-04 | Elevation of Privilege | CLI path args | low | accept | Local CLI trusts the operator for `--out` path (same trust as running Python); no network exposure added |
| T-04-SC | Tampering | pip installs | low | accept | No new packages; argparse is stdlib |
</threat_model>
