## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| argv / env → resolve_max_retries | Untrusted CLI/env integers cross into retry budget |
| process → `--out` filesystem | Write path chosen by user; must write only final validated ExerciseBatch JSON |
| LLM SDK → generators → reliability | API exceptions and response bodies cross into typed errors; must not carry secrets to stderr |
| stderr → developer/user | Stage labels, LOG-01, `[API:*]`, duration aggregate, final PT errors |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Information Disclosure | duration log / LOG-01 / regen UX | high | mitigate | Aggregate line = `total_ms` + `chamadas` only (D-16; D-17); never log API keys, prompts, or raw payloads; extend security tests |
| T-05-02 | Information Disclosure | ERR-05 `[API:openai\|gemini]` | high | mitigate | Keep LOG-02 redaction: type + status/code only; redact env key values from any preview strings; no raw `str(exc)` dumps of transport bodies |
| T-05-03 | Tampering | `--out` on multi-attempt | high | mitigate | Write `--out` and stdout text only after final successful `generate_validated_batch` (D-14); tests assert no file on exhausted failure |
| T-05-04 | Denial of Service | retry loop | medium | mitigate | Hard bound `max_retries ∈ {0,1,2,3}`; no `while True`; tests assert call_count ≤ 1+N; no sleep libraries that could hang UX indefinitely |
| T-05-05 | Information Disclosure | final PT error after exhaustion | medium | mitigate | Print last validation/invalid-response reason only once at end (D-13); permanent API errors still use existing plain PT mapper messages without secrets |
| T-05-06 | Elevation of Privilege | `--out` path | low | accept | Local CLI trusts operator for output path (same as Phase 4) |
| T-05-SC | Tampering | dependencies | low | accept | No new pip packages; stdlib `perf_counter` + argparse/env only |
