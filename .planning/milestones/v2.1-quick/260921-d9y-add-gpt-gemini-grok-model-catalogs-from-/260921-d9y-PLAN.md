# Quick Plan: Model catalogs from Modelos.txt

## Goal

Centralizar as listas de modelos de `Modelos.txt` e usar fallbacks de capacidade (como Gemini hoje) também para OpenAI e Grok — só modelos adequados a **chat/texto** com Structured Outputs (excluir image/tts/audio/realtime/etc.).

## Tasks

### Task 1: `model_catalog.py` + parse Modelos.txt
- Parse `Modelos.txt` (repo root) → `OPENAI_MODELS`, `GEMINI_MODELS`, `GROK_MODELS`
- Derivados: `*_MODEL_FALLBACKS` (filtrados + ordem do arquivo, cap ~12)
- Defaults: primeiro de cada fallback (`DEFAULT_OPENAI_MODEL`, `DEFAULT_GEMINI_MODEL`, `DEFAULT_GROK_MODEL`)
- Helper `model_candidates(preferred, fallbacks)`

### Task 2: Wire generators
- `generator_gemini.py`: usar catálogo; manter walk em capacity errors
- `generator.py`: OpenAI + Grok com o mesmo padrão de fallback; unificar defaults
- Atualizar `token_usage/rates.py` só se necessário (INDISPONIVEL ok para ids novos)

### Task 3: Tests + docs touch
- Testes: parse seções, filtros excluem image/tts, candidates order, monkeypatch fallbacks
- `.env.example` note opcional sobre listas

## Done when
- Catálogos carregam de Modelos.txt
- Três providers têm FALLBACKS + default
- pytest offline verde nos testes tocados
