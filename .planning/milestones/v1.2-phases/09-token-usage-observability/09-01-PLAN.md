## Discretion locked by this plan

| Choice | Value | Rationale |
|--------|-------|-----------|
| NDJSON vs REQUIREMENTS “.json” | NDJSON (`.ndjson`) | Honor D-01 over REQUIREMENTS wording |
| Status enum | `success` \| `error` \| `attempt` | D-12 names |
| Status semantics | `success` = LLM call returned parseable batch; `error` = mapped API/invalid/refusal failure for that call; `attempt` = LLM call completed but validation/math failed and RELY will regenerate (or regenerated after) — tag the completed call that did not finalize the run | Distinct RELY/error/success events |
| Schema types | `ts`: ISO-8601 local str; `provider`/`model`/`status`/`run_id`/`error_kind`: str; token fields: `int \| Literal["indisponível"]`; `duration_ms`: int; `usd`: `float \| Literal["indisponível"]`; `usd_source`: `api` \| `rate_table` \| `indisponivel` | D-16 |
| Flush site | **Single** `flush_token_usage()` only inside `main.run` `finally` (covers success and `sys.exit` via `SystemExit`). Do **not** also call flush before `sys.exit`. `flush()` must clear the in-memory buffer after successful append so a second call is a no-op (idempotent) | D-04 once per run; prevent duplicate NDJSON lines |
| Day partition | `datetime.now().astimezone().date().isoformat()` (local machine TZ) | D-02 |
| Injectable path | Module `TOKEN_USAGE_DIR` default `Path(__file__).resolve().parent.parent / "token-usage"` from inside `token_usage` package | Mirror `POSTMORTEM_PATH` |
| Rate table seeds | Document approximate rates for `gpt-4o-mini`, common Gemini model id(s) used in repo, and Grok default model fallback only when ticks absent | D-17 |
| `[USAGE]` line shape | `[USAGE] provider=… model=… status=… in=… out=… total=… duration_ms=… usd=…` | D-07; no secrets |
| No new PyPI deps | stdlib + existing openai/google-genai only | AI-SPEC Framework None |
